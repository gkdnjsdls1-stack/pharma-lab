# pharma-lab

실제 화학으로 푸는 방탈출. 여덟 개의 방, 여덟 가지 응급 상황.
환자를 살리려면 약을 직접 만들거나, 고르거나, 재야 한다.

| 방 | 상황 | 기법 |
|---|---|---|
| 1 아스피린 | 심근경색 | 합성 · 재결정 · 융점 |
| 2 경구수액 | 콜레라성 탈수 | 정성분석 · 조제 · 농도 |
| 3 퀴닌 | 말라리아 | 추출 · 형광 |
| 4 페니실린 | 패혈증 | 배양 · 역가 |
| 5 메탄올 중독 | 밀주 | 증류 · 비중 |
| 6 수혈 | 대량 출혈 | 혈액형 판정 · 교차시험 |
| 7 소독액 | 충수염 | 적정 · 종말점 |
| 8 마취 | 수술 | 안정성 검사 · 정제 |

**화학 값은 전부 문헌값이다.** 분자량도, 융점도, 투여량도 난이도 때문에 바꾸지 않았다.
대신 **플레이어는 계산을 하지 않는다** — 색, 모양, 눈금, 그리고 방 안에 흩어진 숫자만 본다.

기획과 설계 판단은 [DESIGN.md](DESIGN.md)에 있다.

## 해보기

브라우저에서 `index.html`을 연다. 빌드는 없다.
3D는 three.js r128을 CDN에서 가져오므로 **인터넷이 필요하다.**

## 검산

```
node chem.js        # 방마다 화학 자체점검 (ors / quinine / penicillin / methanol / blood / bleach / ether)
node playtest.js    # 여덟 방을 전략별로 400시드씩 돌려 설계 경계를 지킨다
```

`playtest.js`가 묻는 것은 하나다 — **단서를 읽은 사람과 찍은 사람의 성적이 갈리는가.**
